Add each new change under "Unreleased" with its date as `- YYYY-MM-DD: what changed`. At release, rename the heading to the version and release date.

## 4.2.0 (2026-11-17)

- 2026-11-16: builds for RimWorld 1.6 and 1.7 from one source, into the `1.6` and `1.7` load folders, selected by `LoadFolders.xml`; `About/About.xml` supports 1.6 and 1.7. Fluffy's prebuilt `Assemblies/Fluffy_Relations.dll` is no longer committed. The mod still references only the game.
- 2026-11-16: identity. The mod is "Relations Tab (rimhunter)" with packageId `rimhunter.relationstab`, version 4.2.0, author "Fluffy, rimhunter", and its own `<url>`. `About/About.xml` lists `incompatibleWith` for `Fluffy.FluffyRelations` (Fluffy's Relations Tab and "Relations Tab (Continued)"), `ckvam.relationstab.separatebutton` ("Relations Tab - Separate Button") and `jia.RelationsTabLanguage` ("Relations Tab Language", which needs Fluffy's package and patches his types), so RimWorld's mod list warns when one is enabled with this mod.
- 2026-11-16: removed `About/PublishedFileId.txt` (Fluffy's Workshop item id), `About/Manifest.xml` (Fluffy's version manifest, which pointed at his repository), `modinfo.json` (Fluffy's tool configuration) and `Source/description.md`. `Readme.md` is adapted, credits Fluffy and no longer asks for donations.
- 2026-11-16: new preview image `About/Preview.png`, a screenshot of the tab in the game. Fluffy's preview image and the files used to make it (`Source/preview.png`, `Source/preview.svg.bak`, `Source/Images/`), which used a Freepik family tree icon licensed BY-NC and Flaticon icons, are no longer in the repository.
- 2026-11-16: translations. Every language folder of v4.1.124 is kept with every key (Chinese Simplified and Traditional, English, French, German, Korean, Portuguese Brazilian, Spanish, Spanish Latin). The DefInjected files of French, German and Portuguese Brazilian sat directly in `DefInjected`, where the game does not read them; they moved into `DefInjected/MainButtonDef`. The Chinese folders named the old def type `MainTabDef`, which the game rejects as "doesn't correspond to any def type"; they moved to `MainButtonDef`. File contents are unchanged, except that the French, German and Portuguese Brazilian entries now name the main button `RelationsTab` instead of `Factions`.
- 2026-11-16: added `WORKSHOP.md`, the Steam BBCode page text, and `scripts/test-identity`, which checks the identity, license, translations, preview, Workshop text and package contents.
- 2026-11-16: the Mod Options category (English key `Fluffy_Relations`) reads "Relations Tab (rimhunter)" instead of "Fluffy Relations". Other languages keep their own text for it.
- 2026-11-17: Relations has its own bottom bar button, the def `RelationsTab` (order 91), instead of reusing the vanilla `Factions` def as Fluffy's version did. The vanilla Factions button is hidden by default, so Relations sits in its place; the new setting "Keep the vanilla Factions tab" (off by default, saved as `KEEP_VANILLA_FACTIONS_TAB`) shows the vanilla button beside it. The button is applied at startup, when a game loads and when the settings window closes, so no restart is needed. Fluffy's saved settings cannot carry over, because the game keys a mod's settings file by the mod folder.
- 2026-11-17: the force-directed layout keeps every node inside the graph area at any node count: the whole 70 px slot is clamped inside, also while dragging, and each iteration's movement is capped at half a slot, falling with the temperature (Fluffy's code let nodes fly out of view). The areas are sized from the window's canvas instead of the screen and are rebuilt when the resolution changes. Nodes that sit on the same point are pushed apart in opposite directions instead of stacking. The spacing and force scale with the node count (density scaling), so 30 or more factions spread across the area instead of collapsing into a clump.
- 2026-11-17: the factions page shows every visible faction, as the game's own Factions tab does: factions with no leader are drawn with their faction icon in the faction color (and only that icon, not again in the corner of the slot), hidden factions are left out, the "has no leader" warning is gone, and the page rebuilds when a mod makes a faction visible while the tab is open. The line between two factions and the row in the details both read the game's live goodwill, so they always agree (Fluffy's line read the other side, which disagreed with the row when a mod set only one side).
- 2026-11-17: graph nodes can be clicked on RimWorld 1.7. The 1.7 button only completes a click when its rectangle is the same on mouse down and up, and a node that is still moving never received its click. Clicks are now read from the mouse events for colonist and faction nodes alike. Clicking a faction's row in another faction's details selects that faction.
- 2026-11-17: fixed an error when a colonist has a bonded animal (RimWorld Anomaly): social thoughts are only gathered between humanlike pawns, because an animal has no story and made a Joyous thought throw. Fixed an error when opening the tab with no map loaded (the colonist list is empty instead of throwing).
- 2026-11-17: removed the key `Fluffy_Relations.NoPawn` ("NULL"). Every node now has a pawn or draws its own faction icon, so a slot without a pawn is a programming error and throws instead of drawing a marker.
- 2026-11-17: the Relations bottom bar button label is translated again in Chinese Simplified, Chinese Traditional, Korean, Spanish and Spanish Latin (`DefInjected/MainButtonDef/RelationsTab.xml`), using each language's existing word for relations from its `Fluffy_Relations.Relations` key. Fluffy's button reused the vanilla `Factions` def, so these players saw the game's own translation of "Factions" on it; the new def had no translation and read English. No description is translated for them: none of their translators wrote one.
- 2026-11-17: the "change leader" button in the faction details panel is drawn inside the panel, left of the scrollbar, and can be clicked (Fluffy's issue 38). The details text is laid out in the width left of the scrollbar, so nothing is cut off under it. Choosing a leader keeps the colony's details open instead of closing them.
- 2026-11-17: a new game or a loaded save no longer inherits the chosen colony leader of the game played before it in the same session.
- 2026-11-17: every label and tooltip the tab, its details panels and its settings window draw comes from a translation key. The "mainly believes in" tooltip and the leaderless faction text (key `Noone`, which had no text and showed the raw key; it now uses the game's own `Nobody`) are keyed. A language without a key shows the English text. The translation keys are the ones in each language's `Keyed/Keys.xml`; the key `Fluffy_Relations.NoPawn` (the "NULL" empty-slot marker) is gone, see below.
- 2026-11-17: known limit: in Chinese Simplified, Chinese Traditional, Korean, Spanish and Spanish Latin the description in the tooltip of the Relations bottom bar button is English until a translator writes it; only the label is translated.
