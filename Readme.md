# Relations Tab (rimhunter)

A continuation of [Relations Tab](https://steamcommunity.com/sharedfiles/filedetails/?id=709317151) by Fluffy, for RimWorld 1.6 and 1.7, by rimhunter. It is built from Fluffy's own source, [fluffy-mods/RelationsTab](https://github.com/fluffy-mods/RelationsTab), release v4.1.124. rimhunter claims no ownership of the original. This mod will be taken down or handed back at Fluffy's request.

The relations tab shows, in a very graphical way, relations between your colonists and with other factions.

Do not run another Relations Tab build alongside this one. RimWorld's mod list warns you when Fluffy's Relations Tab, "Relations Tab (Continued)" or "Relations Tab - Separate Button" is enabled together with it.

## Notes

In games with many faction mods or a lot of colonists, the dynamic displays may 'explode'. There are three things you can do to mitigate this problem:

- Use the static circle view. In the top right of the tab there is a button to switch between circle and dynamic views (may be hidden underneath the tutorial window).
- Reset the dynamic view until it stops exploding. The button to reset the dynamic algorithm is in the top right of the window, next to that for circle view (and may also be hidden by the tutorial).
- Tweak the parameters for the dynamic algorithm. In the mod options (Menu -> Options -> Mod Options -> Relations Tab (rimhunter)) you can tweak the parameters for the algorithm. There is a short description of what each parameter does in the options as well.

## Known issues

- In games with a lot of factions or colonists, the algorithm may 'explode'. See the 'Notes' section on how to fix this.
- Some mods (noticeably, the Zabrak faction) change pawn rendering in such a way that it breaks the relations tab.
