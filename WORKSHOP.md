[h1]Relations Tab (rimhunter)[/h1]

The relations tab shows, in a very graphical way, the relations between your colonists and with other factions. Works on RimWorld 1.6 and 1.7 from one subscription.

This is a continuation of Fluffy's Relations Tab: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=709317151]Fluffy's Workshop page[/url] and [url=https://github.com/fluffy-mods/RelationsTab]Fluffy's source on GitHub[/url]. It is built only from Fluffy's own source (release v4.1.124); no code or files from any other Relations Tab build were used.

[h2]Notes[/h2]

In games with many faction mods or a lot of colonists, the dynamic displays may 'explode'. There are three things you can do to mitigate this problem:

[list]
[*]Use the static circle view. In the top right of the tab there is a button to switch between circle and dynamic views.
[*]Reset the dynamic view until it stops exploding. The button to reset the dynamic algorithm is in the top right of the window, next to the one for circle view.
[*]Tweak the parameters for the dynamic algorithm in the mod options (Menu, Options, Mod Options, Relations Tab (rimhunter)). Each parameter has a short description.
[/list]

[h2]Factions tab[/h2]

By default this mod replaces the vanilla Factions tab, as Fluffy's did. If you want both, turn on the setting "Keep the vanilla Factions tab" in the mod options. Turning it on also brings back the buttons that other mods add to the vanilla Factions screen (More Faction Interaction, VFE Classical).

[h2]More Faction Interaction[/h2]

More Faction Interaction's faction-war panel in this tab hooks only into a mod named exactly "Relations Tab", so it does not appear with this continuation.

[h2]Known issues[/h2]

[list]
[*]In games with a lot of factions or colonists, the algorithm may 'explode'. See Notes.
[*]In Chinese (Simplified and Traditional), Korean, Spanish and Spanish Latin the description in the tooltip of the Relations bottom bar button is English until it is translated; only the label is translated.
[*]Some mods (noticeably, the Zabrak faction) change pawn rendering in such a way that it breaks the relations tab.
[/list]
